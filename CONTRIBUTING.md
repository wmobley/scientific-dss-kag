# Contributing

Read the README, student guide and design decisions. Install `.[dev]`, run `python -m pytest -q`, and reproduce `scientific-dss benchmark`. Keep the portable ontology separate from backend mappings. Add behavioral tests for provenance, applicability boundaries and unavailable integrations. Substantial/API/schema changes need a reviewed design. Never mark mocked integration tests as live verification. Do not add automated model execution, publication or destructive migration without explicit authorization.
